# محدودیت‌های iOS برای PWA

چیزهایی که قبل از وعده‌دادن هر قابلیتی باید بدانی. این‌ها محدودیت سافاری‌اند،
نه چیزی که با کد بهتر حل شود.

## نصب

- **هیچ پرامپت نصبی وجود ندارد.** رویداد `beforeinstallprompt` در iOS پشتیبانی
  نمی‌شود. کاربر باید خودش دکمهٔ اشتراک‌گذاری را بزند و
  «Add to Home Screen» را انتخاب کند.
- به همین دلیل در `app.js` یک راهنمای کوچک گذاشته‌ایم که فقط یک بار،
  فقط در iOS، و فقط وقتی اپ هنوز نصب نشده نمایش داده می‌شود.
- تشخیص نصب‌بودن: `window.navigator.standalone === true`.

## نوتیفیکیشن

- Web Push از **iOS 16.4** به بعد کار می‌کند، اما **فقط** اگر اپ روی صفحهٔ
  خانه نصب شده باشد. در تب سافاری هیچ نوتیفیکیشنی ممکن نیست.
- یعنی «پاسخ استاد آماده شد» را نمی‌توان به‌صورت قابل‌اتکا با Web Push به
  کاربر رساند.
- **راه‌حل ما: تلگرام.** چون احراز هویت از همان‌جاست، اطلاع‌رسانی هم از
  همان‌جا می‌رود. این تصمیم محصول است، نه راه‌حل موقت.

## ذخیره‌سازی

- سقف حدود **۵۰ مگابایت**.
- اگر کاربر حدود **هفت روز** اپ را باز نکند، کش پاک می‌شود.
- iOS وقتی حافظهٔ دستگاه کم شود، کش‌ها را زودتر هم پاک می‌کند.

نتیجهٔ عملی: **وعدهٔ «همهٔ کتاب آفلاین» را نده.** پوستهٔ اپ کش می‌شود و
مقالاتی که کاربر خوانده network-first با fallback کش می‌مانند. همین.

## چیدمان

- `100vh` نوار پایین سافاری را حساب نمی‌کند و محتوا زیرش می‌رود.
  استفاده کن از `100dvh` و `-webkit-fill-available` به‌عنوان fallback.
- برای آیفون‌های ناچ‌دار: `viewport-fit=cover` در متا تگ، سپس
  `env(safe-area-inset-top / bottom)` در CSS. بدون آن تگ، مقادیر صفر برمی‌گردند.
- `apple-mobile-web-app-status-bar-style: black-translucent` باعث می‌شود
  پس‌زمینه زیر نوار وضعیت برود — فقط وقتی درست دیده می‌شود که چیدمان
  safe-area را رعایت کرده باشد.

## API هایی که نیستند

Background Sync، Periodic Sync، Background Fetch، Web Bluetooth، Web NFC،
Web USB، File System Access.

یعنی هیچ کاری در پس‌زمینه انجام نمی‌شود. هر همگام‌سازی باید وقتی اپ باز است
اتفاق بیفتد.

## اندازهٔ صفحه

طراحی فیگما ۳۶۰×۸۰۰ (مرجع اندروید) است، ولی آیفون‌های رایج عریض‌ترند:

| دستگاه | عرض منطقی |
|---|---|
| iPhone SE | ۳۷۵ |
| iPhone 14/15 | ۳۹۰ |
| iPhone 16 | ۳۹۳ |
| iPhone 17 | ۴۰۲ |

برای همین کد سیال است و هیچ‌جا عرض ثابت ندارد. `--content-max` فقط عرض
خط متن را برای خوانایی محدود می‌کند، نه عرض صفحه را.
